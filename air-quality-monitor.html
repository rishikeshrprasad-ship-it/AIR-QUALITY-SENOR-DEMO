01 — Introduction

The Air We Breathe Is at Risk

Air pollution is one of the most pressing environmental challenges of the twenty-first century. Rapid industrialization, vehicular emissions, and domestic activities have led to the accumulation of harmful gases — including carbon dioxide, ammonia, benzene, nitrogen oxides, and volatile organic compounds — in the atmosphere, posing severe risks to human health and ecological balance.

Despite its severity, air quality monitoring remains largely inaccessible to the general public due to the high cost and complexity of professional monitoring equipment. This project bridges that gap with a low-cost Arduino-based prototype.

04 — Background Theory

The Science Behind It

Air pollution refers to the presence of substances in the atmosphere harmful to health, other living organisms, or the environment. Pollutants may be gaseous (CO₂, SO₂, NOₓ, ozone, VOCs) or particulate (PM2.5, PM10, dust, soot).

Primary pollutants are emitted directly from a source — carbon monoxide from vehicle exhaust. Secondary pollutants form through atmospheric chemical reactions — ground-level ozone forms when NOₓ and VOCs react in sunlight. Health effects range from respiratory irritation and cardiovascular disease to cancer and neurological damage.

CO₂SO₂NOₓPM2.5PM10OzoneVOCsBenzene

The MQ-135 is a metal oxide semiconductor (MOS) gas sensor by Hanwei Electronics. It operates on chemiresistance: the electrical resistance of a tin dioxide (SnO₂) sensing layer changes in the presence of reducing or oxidizing gases. A heating element raises the sensing layer to ~200°C.

The sensor outputs an analog voltage that decreases as gas concentration increases. This is read by Arduino's 10-bit ADC, producing values 0–1023. It is sensitive to NH₃, NOₓ, alcohol, benzene, smoke, and CO₂ — making it a broad-spectrum air quality indicator.

The Arduino Uno R3 is an open-source microcontroller board based on the Atmel ATmega328P. It features 14 digital I/O pins, 6 analog input pins (10-bit ADC), a 16 MHz clock, and USB connectivity for programming and serial communication.

It bridges the physical world and digital logic — reading analog sensor voltages, making threshold decisions, driving output devices (LED, buzzer, LCD), and communicating with a computer over serial at 9600 baud.

07 — Methodology

How the System Works

⚡
Power On → Warmup Phase
System displays "Warming up..." on LCD for 10 seconds while MQ-135 heating element reaches ~200°C operating temperature. Prevents false alerts from cold-start sensor drift.
📖
Read Sensor (every 200ms)
Arduino reads analog pin A1 from MQ-135. Produces integer 0–1023 via 10-bit ADC. Displays "Gas Level: [value]" on LCD row 0 and serial monitor.
🔍
Threshold Check (> 400?)
Comparator logic checks ADC value against threshold 400. Boolean flag isAlerting prevents unnecessary LCD rewrites — state changes only trigger once per event.
🚨
Alert → LED on + Buzzer 1kHz
When gasValue > 400: LED on pin D2 switches HIGH, tone(BUZZER_PIN, 1000) produces 1 kHz tone, LCD row 1 shows "GAS Detected!". isAlerting = true.
✅
Clear → LED off + noTone()
When gasValue drops ≤ 400: LED switches LOW, noTone() silences buzzer, LCD row 1 shows "Status: Safe". isAlerting = false.
// REAL-TIME AIR QUALITY MONITORING — ARDUINO CODE #include <Wire.h> #include <LiquidCrystal_I2C.h> LiquidCrystal_I2C lcd(0x27, 16, 2); const int GAS_SENSOR_PIN = A1; const int LED_PIN = 2; const int BUZZER_PIN = 3; const int THRESHOLD = 400; bool isAlerting = false; void setup() { Serial.begin(9600); lcd.init(); lcd.backlight(); pinMode(LED_PIN, OUTPUT); pinMode(BUZZER_PIN, OUTPUT); lcd.setCursor(0, 0); lcd.print("Warming up..."); delay(10000); lcd.clear(); } void loop() { int gasValue = analogRead(GAS_SENSOR_PIN); lcd.setCursor(0, 0); lcd.print("Gas Level: "); lcd.print(gasValue); lcd.print(" "); if (gasValue > THRESHOLD && !isAlerting) { digitalWrite(LED_PIN, HIGH); tone(BUZZER_PIN, 1000); lcd.setCursor(0, 1); lcd.print("GAS Detected! "); isAlerting = true; } else if (gasValue <= THRESHOLD && isAlerting) { digitalWrite(LED_PIN, LOW); noTone(BUZZER_PIN); lcd.setCursor(0, 1); lcd.print("Status: Safe "); isAlerting = false; } delay(200); }

11 — EVS Connection

Linking Science to Reality

This project directly applies concepts from Unit III (Air Pollution) of the EVS syllabus (25CE101) to a real-world engineering prototype.

🏭
Sources of Air Pollution
The sensor's response to cooking smoke, vehicular exhaust, and chemical vapors corresponds to the primary anthropogenic pollution sources — combustion, industrial emissions, and solvent evaporation.
🫁
Health Impacts
The alert threshold of 400 is a simplified analog of the AQI categories used by India's Central Pollution Control Board (CPCB). High AQI values correspond to increased health risks, especially for respiratory conditions.
📡
Monitoring & Regulation
The real-time display and serial logging mirror the methodology used by official air quality monitoring stations — providing hands-on understanding of how environmental data is gathered.
🌱
Mitigation Strategies
Reinforces the value of monitoring as the first step in pollution control. You cannot manage what you cannot measure — connecting to policy discussions on emission standards and green zones.

13 — Future Scope

Where This Goes Next

📐
PPM Calibration — Use the Rs/Ro method from the MQ-135 datasheet to provide readings in parts per million (ppm) rather than raw ADC values.
🌡️
DHT22 Integration — Add temperature and humidity sensor to compensate for environmental variations in gas sensor output.
☁️
Wi-Fi Cloud Logging — Integrate ESP8266/ESP32 to upload readings to ThingSpeak or Blynk for remote monitoring and data logging.
📱
Mobile Dashboard — Implement a web/mobile app to visualize historical air quality trends and push notifications.
🔬
Multi-Sensor Array — Replace single sensor with MQ-2, MQ-7, MQ-135 + dust sensor array for comprehensive air quality profiling.
📲
GSM SMS Alerts — Add GSM module to send SMS alerts when dangerous gas levels are detected in remote deployments.
🏠
Weatherproof Housing — Enclose the project in an IP65-rated housing for outdoor permanent deployment.
